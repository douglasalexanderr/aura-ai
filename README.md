# AURA AI v0.3

MVP funcional de marketing autónomo y CRM.

## Incluye

- Generación de campañas
- Guiones de video
- Publicaciones para redes sociales
- Calendario de 7 días
- Flyer SVG descargable
- Historial de campañas
- CRM básico con estados
- Dashboard
- Base de datos SQLite

## Inicio rápido en Windows

1. Extrae el proyecto.
2. Abre `backend`.
3. Ejecuta `start_aura.bat`.
4. Abre `http://127.0.0.1:8000`.
